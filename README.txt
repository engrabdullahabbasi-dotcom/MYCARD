RAJA AMMAR — DIGITAL 3D BUSINESS CARD

Open index.html in a browser to preview.

IMPORTANT BEFORE PRINTING THE QR:
1. Deploy this folder to your final URL, e.g. https://yourdomain.com/raja-ammar
2. Generate a QR code pointing to that final URL.
3. Replace assets/qr-placeholder.png with the final QR image.

The physical card design is recreated as HTML/CSS, so the text and layout are editable rather than being a single flattened image.

Main files:
- index.html — entire interactive experience
- assets/imarat-logo.png — extracted logo reference
- assets/imarat-building.jpg — extracted development image
- assets/qr-placeholder.png — temporary QR only
